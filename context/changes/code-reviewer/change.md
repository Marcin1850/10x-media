## Notes

Chcę stworzyć pierwszą wersję agenta do code review opartego o Claude Code SDK. Ma być osobną paczką w katalogu packages/code_reviewer. Cel zmiany to uruchomienie agenta na testowym (bardzo prostym) wygenerowanym przez LLM diffie. Dokumentację możemy ściągnać przy użyciu context7 i zapisać w folderze /docs do przyszłego użycia.
