This is the whole reason --attention exists. It was originally bound to --accent, which shadcn already uses as the hover surface for ghost and outline buttons — so every ordinary mouse-over would have flashed the colour reserved for spending money. Splitting the token fixed it without touching button.tsx or dialog.tsx.

Rendering it needs data the endpoint does not return yet. The 409 body is currently { requiresConfirmation, cost, transcriptLength } — no title, channel or duration. Metadata is fetched earlier in the same request, so those fields can be added to the response; add fields, do not move the call — its placement is load-bearing for rate spacing, early exits and allowLong resubmits.
