Three channels, never one. Shape (hollow ring vs filled square), weight (500 vs 700), and only then tone. Both badges sit on neutral tokens: sharing --attention would put descriptive metadata at the same visual urgency as a request for money, and giving Educational its own colour would add a third hue to a palette deliberately kept restrained so the ground never competes with YouTube thumbnails.
The result is that amber stays unambiguous — it appears if and only if the app is waiting for your decision.
